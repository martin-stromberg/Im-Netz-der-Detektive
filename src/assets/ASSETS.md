# Rasterassets (KI-generiert)

Die Bilder in diesem Verzeichnis wurden mit
[Pollinations.ai](https://image.pollinations.ai) generiert (kostenlos,
kein API-Key) und sind **lokal eingebettet** — es gibt keine
Hotlinks und keine externen Requests zur Laufzeit.

## Lizenz / Sichtprüfung

- Pollinations.ai gibt generierte Bilder laut Plattform frei zur
  Nutzung heraus (Stand: Abruf 2026-10-14); eine lizenzrechtliche
  Endprüfung obliegt dem Polishing-Schritt 14.
- Alle Dateien wurden nach dem Download auf Format und Inhalt geprüft
  (gültige JPEGs, 768×768, im Anwendungskontext gerendert). Bei
  Bedarf können sie in Schritt 14 durch höherwertige Assets ersetzt
  werden.
