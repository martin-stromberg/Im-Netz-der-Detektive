# Kartenpakete

Die spielbaren Stadtkarten von „Im Netz der Detektive" — jede Stadt ein
eigenes Paket mit Orten, Wegen, Startregeln und karteneigenen
Einstellwerten. Mitgeliefert werden die Hauptkarte **Münster** und die
bewusst unbalancierte Validierungskarte **Lübeck-Altstadtinsel**.
